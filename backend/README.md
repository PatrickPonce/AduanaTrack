# backend

API de AduanaTrack (autenticación, clientes/importadores, despachos, embarques/BL, indicadores).

> Stack por definir por el equipo. Al crear el proyecto aquí (p. ej. `pom.xml`, `package.json` o `requirements.txt`), el workflow **CI** lo detecta y compila/prueba automáticamente; recuerda agregar el lenguaje en `codeql.yml` y el ecosistema en `dependabot.yml`.
